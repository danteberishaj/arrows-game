## Decisions

1. Used 5x5 for both boards. The common grid keeps the teaching transition stable, exceeds the
   48 dp floor by 19.68 dp/cell at W1-01's smallest logged viewport, and is width-limited rather than
   header-height-limited at that geometry.
2. T1 uses six outward-facing two-cell arrows. Every initial tap is legal while the board still
   demonstrates all four exit directions.
3. T2 uses one right-edge legal arrow and four arrows whose lanes visibly meet another arrow. Its
   starting state has exactly one exit without introducing any ordering or puzzle framing.
4. Did not call or import `LevelGenerator` at runtime. The only `GeneratedLevel` import is type-only.
5. Added derived `targetCells` compatibility metadata because current `GeneratedLevel` gained this
   required analysis field in committed W3-01 after the W1-02 brief was written. It equals authored
   occupied-cell count; all brief-specified values remain verbatim (`hearts: 3`, Normal difficulty,
   parsed board count, empty shape name, and empty mask).
6. Did not revert committed W3 work to force the historical-base diff empty. That would violate task
   scope and destroy previously integrated work; the current working-tree protected diff is the
   accurate proof of what W1-02 changed.
