## Decisions

1. **Flag name** `META_THEME_TRANSITION` for the brief's `themeCrossfade` (the controller's `META_X` rule; "crossfade"
   would mislabel a dip through a flat colour).
2. **The toggle logic lives in a new `src/ui/themeTransition.ts`** (not in the brief's Files) so it can be unit-tested;
   App.tsx only wires it. W2-04's primitives are reused unchanged; the only addition is `withRestSignal`, a driver
   wrapper, because the scrim's colour may only change back at rest and W2-04's sequencer has no completion signal.
3. **The scrim colour is a latch set in the swap commit** (`swappedTo`), not state set at the press: at rest the colour
   is already the destination, so the first cover frame can never show the old colour.
4. **Reduced motion: no scrim** (owner ruling 2026-09-25 for W2-04, applied per the dispatch), so the brief's "scrim ends
   at 0" holds trivially (never mounted) and the swap is today's cut.
5. **`useSharedValue(0)` is called in App unconditionally** (GameScreen's W2-04 precedent): with the flag OFF it is one
   unused shared value, never attached to a view; the OFF pixel diff is 0.
6. **Write count measured at the storage layer** with a temporary sqlite trigger instead of a temporary log line, so the
   APK under test is the committed code; the JS-level count is pinned by jest.
