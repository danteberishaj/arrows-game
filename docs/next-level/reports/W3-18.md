## The gallery rule

**The gallery lists an id if and only if a player can currently be dealt it.** That means the id is in one of:

- v1's tier pools;
- any `DAILY_VERSIONS` pool;
- `V2_ADMITTED_SHAPE_IDS`, only when `GEN_V2_ENABLED` is on.

A listed id also must not be retired. This is `src/ui/galleryShapes.ts` `galleryShapeIds()`. `galleryWall` rules:

- A listed id always has a tile.
- An unlisted id (retired, or awaiting W3-19) has a tile only if the player collected it. This is W4-09's retired rule, extended.
- "N of M" counts listed ids only, so it stays "N of 26" today.

Collection bits 26–29 stay reserved in the low 30-bit key. They fold as usual once a generator deals the shape. There is no persisted-schema change, so there is no migration and no wipe risk: no key is added and no existing bit moves.

## Decisions

- **The admission list is fail-closed** (`V2_ADMITTED_SHAPE_IDS`) rather than a pending set. A future author who forgets to mark a shape can never leak it into v2.
- **A collected-but-unlisted id still shows**, uncounted. This matches W4-09's retired rule, and it never takes an owned tile away. Today it can only happen after a downgrade from a build that admitted the shape.
- **A scheduled daily pool counts as "dealable".** Past days never change, and a scheduled entry is a commitment to deal it.
- **`shape-preview`, the W3-04 tool, now iterates `SHAPE_CATALOGUE`** in catalogue order instead of the pool union. Otherwise it could not preview an unpooled shape. It prints `pending W3-19` and has a new `--ids` option.
- **`difficulty-probe` shape-report changes:** "admitted/excluded everywhere" now ranges over bag candidates only, plus a "Not bag candidates" line. Without this, pending shapes would be misreported as excluded by capacity.
- **`daily-band.ts` `POOL_26`** is now `SHAPE_CATALOGUE.slice(0, 26)`. It would otherwise have silently become a 30-shape pool.
- **Mid-game = displayed level 200** (`MID_GAME_LEVEL`, OWNER-PICKED STARTING VALUE): half way to the curve's saturation at 400.
- **The House patch adds `V2_SHAPE_DEFINITIONS`** (v1's map plus the new shapes) as `NEWEST_SHAPE_DEFINITIONS`. This follows `shapeCatalogue.ts`'s own seam comment.
