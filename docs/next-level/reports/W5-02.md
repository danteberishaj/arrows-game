## Decisions (routine judgment calls)

1. **F20, strike vs icon:** an icon carries its own off shape (sound off = speaker + slash), so HeaderButton draws the
   W0-06 strike only over a TEXT glyph. The "#" grid-lines toggle has no icon in the brief's set and keeps its text
   glyph and its strike (it still becomes a circle). **W7-04's Settings button does not exist at `b17461d`** (no
   `SettingsSheet`), so no `settings` icon was added; W7-04 adds one when it lands.
2. **`icon` is an `IconName`, not a `ReactNode`** (brief: `icon?: ReactNode`): the button owns the glyph's colour
   (active / off / disabled from W0-06's roles) and size; a ReactNode would make every call site recompute them.
3. **The disabled hint icon is `glyphOff` at full opacity.** The 0.35 dimming existed because the colour emoji ignored
   `color` (HeaderButton's own comment); the icon takes the token, and `header-icon-off` gates it at 3:1.
4. **Continue heart colour follows the label** (`inkOnAccent` ready / `inkDim` not ready), see the table.
5. **Accessibility parity, no new strings:** an icon button's label is the glyph it replaced (TalkBack read "♪",
   "☾", "💡", "‹" before and still does), the Continue button keeps its old text as label. Those labels were already
   poor; improving them is out of scope (a copy change).
6. **The circle test's sample point is corrected for the 1 dp border** (below), and both points are reported.

## Frame cost: ON vs OFF inside a same-APK null (EXECUTED; `scripts/run-perf502.sh`, `scripts/ana502p.py`)

- **Method.** Arms P = `w502-off.apk`, A = `w502-on.apk`, N = `w502-off.apk` again (the same-APK null); every run
  `install -r` with the file and on-device sha logged (`perf/{menu,game}/run-log.txt`), scales 1/1/1 read back, cold
  launch. Rotating orders per round (P A N | A N P | N P A | P N A | A P N, repeated), because W5-14 found the
  emulator's RenderThread mode following the leg position. **Menu** (the idle composed menu with its two header
  buttons; the Play pill breathes, so every frame is drawn): W5-14's perf514.mjs (`scripts/perf502m.mjs`): 4 s settle,
  `gfxinfo reset`, 8 framestats dumps 1.5 s apart, de-duplicated. **Game** (the header with back + hint on screen during
  play): W5-03's pace503.mjs (POLISH-T10 exit burst: level 1 at the zoomed opening camera, 27 solve-order exits, one
  framestats window [UP, UP + 1000 ms] per exit), `t11an.py`. **Decision rule, stated in `scripts/ana502p.py` before
  the data:** per metric, effect = median(A) - median(P), null = median(N) - median(P); ON is slower only if the effect
  is > 0, larger than |null| AND the exact permutation p (A vs P) < 0.05. 10 rounds per surface: 5 were run first, then 5 more (the menu's first 5 showed a janky difference
  below significance; the game's first 5 put two ON runs in one slow host window); both stages are reported.
- **Rendered (ruling F02):** every ON menu run's end screenshot shows the circular buttons (the corner pixel is `bg` in
  10/10 A runs and `surface` in 20/20 P and N runs); the ON APK is the file the captures above were taken with.
- **Reconciliation:** menu: P 6873 / 7278, A 7258 / 7423, N 7076 / 7395 frames drawn / expected at 60 Hz over 125.8 /
  124.2 / 125.0 s (10 runs each). Game: P 3702 / 3834, A 3218 / 3413, N 3707 / 3829 over 270 / 243 / 270 one-second
  windows, no truncated window; A has 9 runs (A2 aborted before its first tap: "NOT AT LEVEL 1 START (?)", an empty
