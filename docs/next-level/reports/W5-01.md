## Decisions

1. Every exposed cell side becomes a directed edge with the filled cell on its right.
   At the only ambiguous topology—a vertex shared by diagonal cells—the linker tries a
   right turn before straight or left. That closes each cell component independently
   instead of splicing corner-touching shapes into a self-contacting loop.
2. Loop orientation is deliberately not part of correctness. Every consumer must use
   `fillRule="evenodd"`, so inner loops remain holes regardless of winding direction.
3. The whole mask grid, including false margins and ragged-row gaps, is centred using
   `size / max(rows, cols)`. Missing entries in ragged rows are treated as false.
4. Shape deduplication is by stable shape name while preserving pool order. First-level
   indices and grids are discovered by actual `LevelGenerator.generate` calls rather
   than hardcoded lookup data.
5. The two-panel labels and layout are inspection aids only. Every discretionary numeric
   layout value carries the required `OWNER-PICKED STARTING VALUE` annotation; the
   task-specified 3.5 px/dp density is not presented as a new choice.
