## Decisions

1. **Ink Night keeps its hairline edge in every candidate set** (the numbers above): a lighter Night fill either loses
   the hairline or breaks every panel text row. Depth by value in Night stays the 1.21:1 fill step plus the W0-06
   hairline.
2. **`surfaceRaised` is ONE token for both outcomes**, so a Daylight fill that is raised against the dark win scrim is
   white-on-white against today's lose wash; set C gives both outcomes the same dim scrim instead.
3. **The rendered-edge criterion is reported both ways** (literal and either/or) rather than rewritten.
4. **Captures use the fit camera** and non-PERF builds with a seeded save (the W2-06 precedent), so the real player
   panel (W2-05 presence motion on, W5-04 badge on, W4-06/W4-11/W2-06 code paths as shipped) is what is measured.
5. **Scrim tokens are `#RRGGBBAA` strings**: the `Palette` stays `string`-valued, and RN parses the 8-digit form into
   the same 8-bit alpha as today's `rgba()` literals (0.45 -> 115, 0.86 -> 219).
