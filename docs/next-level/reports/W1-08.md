## Decisions

1. Kept W1-08's formatter and event union standalone, as required by controller ruling F09; it does
   not reuse or send W6 telemetry events.
2. Used compact positional output exactly matching the brief's shapes, for example
   `[ftue] blocked false grace 34` and `[ftue] clear 2 56`.
3. `charged` is the actual result of `blockedTapCost`. `graceOrAssist` is `grace` when tutorial
   grace is consumed, `assist` for the first fresh assisted blocked tap before any removal, and
   `none` otherwise (including a free repeat already covered by the per-arrow ledger).
4. De-duplicated `board_mount` by session object identity so React Strict Mode cannot produce two
   lines for one mounted board. Its timestamp is exactly `0`; all subsequent times use the same
   board-mount clock.
5. Bound `console.log` once at module load. Expo's production transform removed direct application
   `console.log(...)` calls from the Hermes release bytecode; the bound console method preserves the
   explicitly enabled diagnostic logger while every call remains behind the inlined environment
   guard. The OFF device check covers leakage.
6. Updated the contrast audit's exact GameScreen line metadata after the first full gate correctly
   exposed the shifted anchors. This was a mechanical compatibility update only.
