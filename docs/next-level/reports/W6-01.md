## Decisions (routine calls, recorded)

1. **Quiet-period `[mask]` trigger (750 ms), added to the brief's every-50 and unmount triggers.**
   - Why: `startReady` force-stops the app for every sample (read in `benchmark.mjs`), so the board
     never unmounts. Each process makes 3 rebuilds (1 mount + 2 tap), so the brief's triggers alone
     would log nothing in the brief's own command.
   - Timing: 750 ms is past the second rebuild (+340 ms) and past the harness frame window (tap end
     + 540 ms). It logs before the next force-stop, which was observed in every process.
   - The picked number carries `// OWNER-PICKED STARTING VALUE`.
2. **Summary line fields.** The line also prints `minNonZero`, `clockStep` and `new=` (the
   individual durations). The acceptance needs the smallest non-zero value, and per-tap totals and
   the mount/tap split need individual samples.
   - `clockStep` printed at 4 decimals in S1 read 0.0000. It was changed to 6 decimals and
     session S2 was run on the final source, which also gave a replicate.
3. **Prior-session JS-only repack instead of a gradle build**, per the Phase 2 note on disk. The host APK is the
   W0-04 gradle PERF build from `35be887`. Native, plugins, patches and the lockfile are unchanged
   from `35be887` to base (EXECUTED `git diff --stat`: only script entries in `package.json`).
4. **Prior-session `--skip-build --apk`.** The earlier JSON therefore says
   `configurationVerifiedFromFreshBuild: false`; the continuation JSON supersedes that provenance
   limitation with `true`.
5. **Kotlin `Trace` lines are retained.** The continuation built them into a release APK and API 31
   captured the app sections, so the brief's removal/fallback condition does not apply.
6. **The Fabric section is an upper-bound proxy, labelled INFERRED**, never presented as the native
   number.
7. **"Null run" read as re-tapping the same blocked arrow inside its shake window.** The mask does
   not change, so the timer must not fire. The "timer floor" is reported two ways: the Hermes clock
   step (min 0.000041 ms) and the smallest non-zero duration each timer reported.
8. **Level index 11** used its own repack (`EXPO_PUBLIC_PERF_LEVEL=11`) and the head cell (15,17)
   of blocked arrow `15,17,R:LLU` (46×37 board, 54 arrows).
9. **The brief's `--output docs/tmp-mask-timing.json`** was used, then moved to
   `artifacts/W6-01/device/`. It was not committed, because the doc carries the numbers. The S2 run
   overwrote S1's file; S1's JSON is preserved in `benchmark-3827.log`, which is stdout.
10. **Analysis scripts stay in `artifacts/W6-01/scripts/`** (uncommitted). The brief's Files list does
    not include them, and "only P-02 builds a capture instrument". They parse, they do not capture.
    The doc names them.
11. **The emulator was booted with `-gpu host`**, as brief step 5 says; the controller's boot line
    omitted it.
