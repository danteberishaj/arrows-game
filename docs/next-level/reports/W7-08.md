## Decisions

1. Banned phrases are checked over field values only, not the whole file, because the evidence
   list must be able to cite paths such as `src/core/boardLogic.ts` ("logic").
2. Title and name candidates are `title_1..3` / `name_1..3`, each checked against the single
   field's limit.
3. "Costs a heart" rather than "every blocked tap costs a heart": the tap ledger can refund a
   repeat tap on the same arrow (`GameScreen.tsx:557-563`).
4. Ads are mentioned in the description (interstitials between some levels, optional rewarded).
5. No streak, daily board, gallery, banner or review line: flags off, or not in the brief's spine.
