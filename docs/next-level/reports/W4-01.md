## Decisions

- The order-lock compares the locked prefix and separately asserts length 26. Reordering, replacing,
  or inserting an existing index fails; a valid append requires changing only the length assertion.
- Shape definitions live in an explicit v1 id map. The current newest-definition map aliases v1 and
  `shapeDefFor` still performs the required newest-then-v1 fallback, leaving the future version seam
  visible without changing current behavior.
- Jest verification used `--no-watchman` after the required bare command hit the sandbox-only
  Watchman permission failure.

## Concerns

No product or implementation concerns. Watchman cannot initialize inside this sandbox, so the
successful Jest evidence uses Jest's supported `--no-watchman` option.
