## Decisions

1. Kept the exact measured geometry instead of silently changing native density to make the brief's
   incorrect dp parenthetical true.
2. Did not change `GameScreen` to apply a bottom inset. That would be a player-visible layout fix,
   contradicting W1-01's non-goal and expanding the task beyond measurement.
3. Did not invent T1/T2 boards. `--tutorial` recognizes both ids and reads an optional future
   `buildTutorialLevel` core export; until W1-02 lands it throws a precise unavailable message.
4. Kept the small metrics walk local to the W1 CLI. F30 prefers a shared pure function, but moving
   W3-01 analysis into production `src/core` would widen this measurement task and production API.
   The required independent cross-check was executed instead.
5. Used release-Hermes JS repacks only to correct the perf switch and create the flag-disabled arm;
   the one native release build required by the brief was completed first and remained the host for
   both arms.
