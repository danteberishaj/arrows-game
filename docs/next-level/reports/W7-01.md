## Decisions

1. `non-eea` is diagnostic-only and resolves to `gdprApplies=false`, `personalisedAds=true`, and
   `ccpaOptOut=false`. That gives the fixture a concrete allowed state without pretending to infer
   geography in a player build.
2. `lastKnownSource.showPrivacyOptions()` returns the current persisted state and never renders UI.
   This satisfies the CMP-agnostic interface while keeping all consent UI and re-prompt behavior in
   W7-03/W7-04.
3. A post-init consent change reapplies the privacy settings through the exported controller but does
   not destroy or reinitialize LevelPlay. Full gating takes effect on the next cold start, as required.
4. The remote kill check remains before gathering, so a killed ads switch cannot cause a CMP prompt.
5. The diagnostic wrapper logged each call immediately before dispatch; full LevelPlay native logs
   independently confirm each privacy API was received before native init.

### Policy hand-off, decisions, and concerns

- **W7-05 requirement — INFERRED:** policy text must say that an in-session refusal immediately
  disables rewarded continue, rewarded hint, and interstitial surfaces. The already-initialized SDK
  process is not torn down during that session; the next cold start refuses initialization while
  consent remains refused. This supersedes the earlier report's statement that full gating waits
  until the next cold start.
- **Decision — INFERRED:** consent is allowed again only after `applyPrivacy` succeeds; a refused
  result closes surfaces before awaiting that call. This avoids a grant opening ads before the SDK
  accepts the matching privacy state while making withdrawal immediate.
- **Concern — UNVERIFIED-DEVICE:** the original physical-device concerns remain: downstream demand
  handling of `setConsent(false)` is not observable on this emulator. The app-owned surfaces no
  longer depend on that SDK behavior to fail closed.
- **Owner acceptance needed:** No. This fix reuses the accepted W0-02 unavailable state and adds no
  player-visible copy or visual choice.
