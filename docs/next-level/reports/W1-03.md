## Decisions

1. The save accessor deliberately preserves the raw stored integer. Validation belongs to `ftueRoute`, whose invalid-stage branch fails safe to `real`.
2. The stage protocol uses local named constants rather than an exported enum. This keeps the requested public surface to the two functions and one route union while making the numeric meanings explicit.
3. The accessor test uses P-01's existing `RecordingStore`, which is an in-memory `IntStore`; exporting the production-private `MemoryStore` only for this test would expand the API without changing coverage.
4. The literal pre-fix grep result is reported rather than altered or reinterpreted. The narrower symbol/file check demonstrates the missing functionality without re-verifying P-01.
