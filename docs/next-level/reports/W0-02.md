## What changed

- `src/ui/adReadiness.ts` (new, pure TS): `createReadiness(initial=false)` returns `{ get, set, subscribe }`. It notifies only on a real change, and a subscriber can safely unsubscribe itself while being notified.
- `src/ui/adInit.ts` (new, pure TS): `createAdInitController({ attempt, delaysMs, setTimer, clearTimer })` with the states `idle | running | ready | failed`.
  - `start()` does nothing while `running` or `ready`, and never rejects.
  - After a failure it schedules `delaysMs[firedCount]`. A timer that gets cancelled does not count, so at most `delaysMs.length` timed attempts ever fire.
  - `onAppActive()` starts an attempt only in `failed`, and cancels any pending timer first.
  - `AD_INIT_RETRY_DELAYS_MS = [5000, 15000, 45000]` is an OWNER-PICKED STARTING VALUE.
- `src/ui/ads.tsx`
  - Readiness: `syncRewardedReady()` uses the native `rewardedLoaded` once handles exist, otherwise `__DEV__ && fakeAdListener !== null`.
    - `onAdLoaded` sets it true.
    - `onAdLoadFailed`, `onAdDisplayed`, `onAdDisplayFailed` and `onAdClosed` set it false.
    - `AdHost` mount and unmount re-sync it.
  - The store is exposed as `Ads.rewardedReady` (a getter) and `Ads.subscribeRewardedReady(cb)`. There is no polling.
  - `initLevelPlayOnce()` keeps the order init, then assign `lpInterstitial`/`lpRewarded`/`levelPlayApi`, then un-awaited `loadAd().catch(reload)`.
  - `createReloader()` keeps one pending reload per ad and reuses the existing 15 s delay, now named `RELOAD_DELAY_MS`.
  - `initAds()` requires the module once. If that fails there is nothing to retry. Otherwise it calls `adInitController.start()`.
  - Dev logs now go through `adLog()` (`if (__DEV__)`).
- `App.tsx`: `initAds().catch(() => {})`, plus `AppState.addEventListener('change', s => s === 'active' && adInitController.onAppActive())`, removed on unmount.
- `src/ui/HeaderButton.tsx`: new `disabled?: boolean`. It is passed to `Pressable` and to `accessibilityState={{ disabled }}`. A disabled glyph uses the `active=false` colour, **plus opacity 0.35** (deviation 1).
- `src/ui/GameScreen.tsx`
  - `useSyncExternalStore(Ads.subscribeRewardedReady, …)`.
  - The hint is disabled when `!rewardedReady || terminalPending || adBusy`.
  - Continue is disabled when `!rewardedReady || adBusy`, and while not ready it is drawn with a `heartLost` background and `inkDim` text.
  - Lose-panel subtitle: `No ad available right now — Retry is free` when `!rewardedReady || adShowFailed`.
  - `adShowFailed` is set when a show resolves `false`. It is cleared by a readiness change (direct subscription), a board tap (`onRemoved`/`onBlocked`), a new show attempt (deviation 3) or `loadLevel`.
  - During play, `Hint unavailable ·` replaces the mission label (deviation 2).
  - Nothing is granted unless `earned === true`, which is unchanged.
