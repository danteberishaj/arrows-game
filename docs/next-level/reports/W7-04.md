## Decisions

1. **Scrim opacity 0.95, computed, not picked.** The lose panel's 0.86 left the panel's `border` edge at 2.61:1
   (Daylight) / 2.37:1 (Ink Night) against the scrim over the wordmark's ink. 0.95 is the lowest 0.01 step at which
   every menu colour under the scrim keeps ≥ 3:1 (3.14 / 3.07); `scripts/scrim-alpha.ts`, `gates/scrim-alpha.txt`.
   The menu is then only faintly visible behind the sheet (captures). A lighter scrim is an owner taste call that
   would need a different edge treatment.
2. **A centred panel, not a bottom sheet:** the app's one panel language (win / lose), no new motion.
3. **The support address is shown on the row**, so a player with no mail app (the emulator's Gmail has no account)
   can still read it. One extra word on the sheet.
4. **The button sits on the cluster's far left**, so the theme and sound buttons stay exactly where BASE has them
   (device diff box = the new button only).
5. **Ad privacy closes the sheet before the form opens:** UMP's form is its own dialog and must never sit under the
   Modal's window. Policy and Support leave the sheet open (the browser / mail app come back to it).
6. **Type tokens reused, none added:** title `panelTitle`, rows `menuEntry` (the quiet entry-row controls), detail and
   version `menuStats`. W5-08's pinned Type table is unchanged.
7. **Rows read once when the sheet opens** (like the menu's other once-per-mount reads); UMP's
   `privacyOptionsRequirementStatus` only changes after a gather.
