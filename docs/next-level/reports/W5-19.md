## Decisions

1. **The OFF arm keeps the META flags ON.** "Every ART flag OFF" in the dispatch is read as ART only. The META flags
   stay on in both arms so the daily, gallery and settings screens exist. The player build today has every flag off,
   and the packet says so.
2. **The ON arm is the recommended set, not "all available flags"** (the dispatch overrides the brief).
   - Paper texture is excluded (recommendation: no).
   - The trail width cannot be set in a player build (PERF-only override).
   - The header silhouette is included because the recommendation is "keep".
3. **Panel set A in ON is built through a capture overlay.** HEAD's `theme.ts` with 2 value edits
   (`overlay-A/overlay.diff`), identical to W5-05's overlay-A tokens.
4. **Reduce motion and scale per screen.** The static screens are captured at scale 0 (reduce motion on), which gives
   a deterministic Play pill and uiautomator dumps. The panels are captured at scale 1 (reduce motion off), which is
   the player's entrance. The brief asked for both reduce-motion states on every screen; this packet covers each
   screen in one state.
5. **The sheet uses the re-take** for the one anomalous panel capture (concern 1). The original stays in `cap/on/`.
