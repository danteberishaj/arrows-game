## Concerns
1. **Evidence path disagreement.** W0.md's header says W0 evidence goes under `artifacts/w0/<task-id>/`. The controller brief for this run says `artifacts/W0-01/`. I used `artifacts/W0-01/`. W0-07 must look there, or the directory should be moved.
2. **Release coupling (from the brief).** This fix alone turns "Continue +♥ (ad)" and the hint into silent no-ops after a failed init. The recording shows exactly that. It must not be released without W0-02.
3. **Native interstitial path still resets before display.** `showInterstitialIfDue` sets `finishedGames = 0` after `isAdReady()` but before `showAd()` succeeds. If `showAd()` rejects, the counter was reset with nothing shown. That is outside this brief (step 4 limits the change to the non-native branch). Criterion 4's "no code path writes `finishedGames` unless an ad was displayed" is therefore only true for the non-native path. W0-05 should cover it.
4. **Build recipe.** The brief's closing step says `npx expo run:android --variant release`. I used the gradle `assembleRelease -PreactNativeArchitectures=arm64-v8a` recipe that produced the base APK (RELEASE.md), so base and fix are built the same way. Then I installed with `adb install -r`.
5. **Emulator state changed.** emulator-5556 now has the W0-01 release build (`6f3a8b8`) installed with fresh data at Level 2 (the P-01 seeded save was cleared). The seeded data dir is backed up at `artifacts/W0-01/p01-seeded-appdata-backup.tgz`, but restoring it into a different install is not guaranteed. The next task should seed what it needs. Radios are on, scales are 1/1/1, and the app is force-stopped.
6. **Hooks ordering.** `AdHost` returns before its hooks when `!__DEV__`. This is safe because `__DEV__` is a build constant, and in release the component is not mounted at all. A future `react-hooks/rules-of-hooks` lint would flag it. The repo has no ESLint today.
